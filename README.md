# Release Watch Board

Release Watch Board is a web application for tracking movies and TV series.

It allows users to:

- Track upcoming releases
- Monitor release dates
- See release status
- Track watched movies and series
- Track watched episodes
- Search and filter their watch list

## Tech Stack

### Frontend
- React
- Vite
- CSS

### Backend
- Node.js
- Express

### Database
- PostgreSQL

### Scraping
- Playwright

### Scheduling
- node-cron

### Testing

- Vitest

### Deployment
